# Pandas Series Practice

This repository contains my solutions for the 30 questions in the Pandas Series practice set. I have kept the examples short and used basic Pandas operations covered in the questions.

## Files

- `pandas_series_practice.ipynb` - questions, code, outputs and short notes.
- `pandas_series_solutions.py` - the same solutions in a Python file.
- `requirements.txt` - the library needed to run the examples.

## Run the notebook

1. Install Python.
2. Install the requirements:

   ```bash
   pip install -r requirements.txt
   ```

3. Open `pandas_series_practice.ipynb` in Jupyter Notebook or JupyterLab.

You can also run the Python file from a terminal:

```bash
python pandas_series_solutions.py
```

## Topics covered

Creating Series, values and index, label selection, Boolean filtering, membership checks, dictionaries, missing values, Series names, and arithmetic with index alignment.

These are practice solutions. Try changing the values and labels to check how the results change.
